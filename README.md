## 📖 Description
Fabled Roots is a RPG-lite data pack that introduces 10 unique races and 10 diverse classes, along with new weapons, items, spells, and structures. When you first join a world or server, you’ll choose a race and class to shape your playstyle — No worries you can change them anytime down the road from the pause menu. These systems are designed to enhance the classic Minecraft loop, giving your adventure a fresh twist without getting in the way.

## 🧙‍♂️ Races

## 🛠️ Technical Gibberish
Starting with **v1.7** some Aspects can configured in-game by Admins/OPs. `/function fabled_roots` opens the config menu.

**The data pack also functions as the resource pack** for the needed textures and other assets. *(Mod users automatically have the resources enabled)*

For **PaperMC users**, it is recommended to set the `paper.maxChatCommandInputSize` property to a value between 512 and 1024. More information can be found in the [PaperMC Docs](https://docs.papermc.io/paper/reference/system-properties/#papermaxchatcommandinputsize). Also make sure to have `allow-non-player-entities-on-scoreboards` enabled in your paper configs.
